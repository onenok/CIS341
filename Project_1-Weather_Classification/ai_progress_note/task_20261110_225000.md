**重要更正**：官方文件寫 `assisted`，但那不是 `chat.permissions.default` 的值，而是
`chat.defaultConfiguration.approvals`。寫錯 key 會靜默無效。

**`restricted: true` 的真正語意**：不是「只能寫使用者設定」，而是**「需要 Workspace Trust」**
（原始碼：`this.isUntrusted = !!this.setting.restricted && !isWorkspaceTrusted`）。
所以放 workspace 設定是合法的，只在資料夾未被信任時會被忽略。

### 規則比對語意

非正則的 key 會被編譯成 `^<escaped key>\b` → **前綴比對 + 字詞邊界**。
所以 `"Get-ChildItem": true` 可涵蓋 `Get-ChildItem -Recurse -File`。

⚠️ **陷阱**：以引號結尾的 key 永遠比不上，因為 `\b` 需要字詞字元，
`"` 與空白之間沒有邊界。所以 `& "..\.venv\Scripts\python.exe"` 這種指令
**必須用正則**，不能用純字串。

### VS Code 內建「本來就自動放行」的清單

Unix 唯讀：`cd echo ls dir pwd cat head tail findstr wc tr cut cmp which basename dirname realpath readlink stat file od du df sleep nl grep`
PowerShell 唯讀：`Get-ChildItem Get-Content Get-Date Get-Random Get-Location Set-Location Write-Host Write-Output Out-String Split-Path Join-Path Start-Sleep Where-Object Select-Object Select-String Measure-Object Compare-Object Format-List Format-Table Sort-Object`
git：`status log show diff ls-files grep`（支援 `-C <path>` 與 `--no-pager`）
其他：docker 唯讀、npm/yarn/pnpm 唯讀、`column date find rg sed tree xxd sort`

內建「**一律需授權**」的清單：
